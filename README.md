# تطبيق ماسح المستندات — Doc Scanner

تطبيق React Native (Expo) لتصوير أي مستند وتحويله PDF، مع نموذج ربح كامل عبر إعلانات AdMob.

## 📁 هيكل المشروع

```
doc-scanner-app/
├── App.js                     # نقطة الدخول + التنقل بين الشاشات
├── app.json                   # إعدادات Expo (الاسم، الأيقونة، صلاحيات الكاميرا)
├── package.json                # المكتبات المطلوبة
└── src/
    ├── screens/
    │   ├── ScanScreen.js        # شاشة الكاميرا وتصوير المستند
    │   ├── PreviewScreen.js      # معاينة الصورة + زر إعلان مكافأة
    │   └── LibraryScreen.js      # قائمة المستندات المحفوظة + بانر إعلان
    └── utils/
        ├── AdManager.js          # كل منطق الإعلانات (بمكان واحد)
        └── pdfHelper.js           # تحويل الصورة لـ PDF
```

## 🚀 كيف تشغله على جهازك (خطوة بخطوة)

### 1. تثبيت الأدوات الأساسية (مرة وحدة بس على حاسوبك)
```bash
# تأكد إنه Node.js مثبت عندك (نسخة 18 أو أحدث)
node -v

# ثبت أداة Expo CLI
npm install -g expo-cli eas-cli
```

### 2. تثبيت مكتبات المشروع
```bash
cd doc-scanner-app
npm install
```

### 3. تشغيل التطبيق للتجربة

⚠️ **تنويه مهم وصادق**: مكتبة الإعلانات (`react-native-google-mobile-ads`) فيها كود أصلي (native code)، فـ **Expo Go العادي ما رح يقدر يشغلها** — رح تشوف خطأ لو حاولت. عندك خيارين:

**الخيار أ) للتجربة السريعة بدون إعلانات:**
احذف مؤقتاً سطر `import ... from 'react-native-google-mobile-ads'` من `AdManager.js`، وجرب باقي التطبيق (الكاميرا، الحفظ، الـ PDF) عادي بـ Expo Go عبر:
```bash
npx expo start
```

**الخيار ب) لتجربة كل شي متضمن الإعلانات فعلياً (الطريقة الصح للنشر):**
ابنِ "Development Build" مرة وحدة (بديل عن Expo Go، بس بيدعم كل المكتبات):
```bash
eas build --profile development --platform android
```
حمّل الملف اللي بيطلعلك وثبته، وبعدها استخدم نفس الأمر `npx expo start` وبيفتح على هاد الـ build بدل Expo Go — وهون كل شي رح يشتغل فعلياً متضمن الإعلانات.

## 🔑 قبل ما تنشره فعلياً — 3 خطوات ضرورية

### أ) ربط حساب AdMob الحقيقي
1. سجل حساب على [admob.google.com](https://admob.google.com)
2. أنشئ تطبيق جديد، وخذ الـ **App ID**
3. أنشئ 3 وحدات إعلان: Interstitial + Rewarded + Banner
4. افتح `app.json` واستبدل:
   ```json
   "androidAppId": "ca-app-pub-xxxxxxxxxxxxxxxx~xxxxxxxxxx"
   ```
   بالـ App ID الحقيقي تبعك.
5. افتح `src/utils/AdManager.js` واستبدل كل `ca-app-pub-xxxxxxxxxxxxxxxx/xxxxxxxxxx` بالـ Ad Unit ID الحقيقي لكل نوع إعلان.

### ب) تحويل PDF — شغال فعلياً، ما بيحتاج تعديل
`pdfHelper.js` بيستخدم `expo-print` وبيولّد ملف PDF حقيقي وقابل للفتح فوراً، متوافق مع Expo Go والبناء النهائي بدون أي إعداد إضافي. ما في شي لازم تسويه هون.

### ج) بناء نسخة النشر (APK / IPA)
```bash
# لأندرويد
eas build --platform android

# لآيفون (يحتاج حساب Apple Developer مدفوع)
eas build --platform ios
```

## 💰 خارطة الإعلانات بالتطبيق (وين بالضبط كل نوع)

| الشاشة | نوع الإعلان | التوقيت |
|---|---|---|
| بعد تصوير المستند | Interstitial | كل 2 عملية سكان (قابل للتعديل بـ `AdManager.js`) |
| شاشة المعاينة | Rewarded | زر اختياري لإزالة العلامة المائية |
| شاشة المكتبة | Banner | ثابت بأسفل الشاشة دائماً |

## 📝 حالة كل جزء بالتطبيق (بصراحة كاملة)

| الجزء | الحالة |
|---|---|
| الكاميرا وتصوير المستند | ✅ شغال فعلياً بالكامل |
| تحويل الصورة لـ PDF | ✅ شغال فعلياً بالكامل (عبر expo-print) |
| الحفظ المحلي وقائمة المستندات | ✅ شغال فعلياً بالكامل |
| المشاركة والحذف | ✅ شغال فعلياً بالكامل |
| الأيقونة وشاشة splash | ✅ موجودة (تصميم بسيط مبدئي — بتقدر تستبدلها بتصميم احترافي لاحقاً) |
| منطق الإعلانات (متى/كيف تظهر) | ✅ الكود جاهز وصحيح |
| الإعلانات نفسها بـ Expo Go | ⚠️ **ما بتشتغل بـ Expo Go العادي** — لازم Development Build (خطوة "ب" فوق) |
| AdMob IDs الحقيقية | ⚠️ لسا بوضع تجريبي (test) — استبدلها قبل النشر |

**يعني عملياً**: التطبيق جاهز للتجربة والنشر من الناحية التقنية بالكامل. الشي الوحيد يلي لازم إيدك تلمسه فعلياً هو ربط حساب AdMob الحقيقي (خطوة "أ" فوق) — هاد ما حدا غيرك يقدر يسويه لأنه محتاج حسابك الشخصي.
